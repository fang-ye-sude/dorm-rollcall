# 02 · 工作流程

## 一、日常（周日至周四）

```
21:30 前    学生211在 iPad 点名、标四维
21:30~21:40 点「上传标记件」（可再点「立刻填表」）
21:40       定时任务 rc-fill 取件 → 写三表 → 销账
21:45 后    管理者在控制台看「今日一线」是否三步皆绿
23:50       若当晚没传，rc-sweep 再检查一次；仍无 → 不打扰
```

### 学生211那一侧（iPad）

1. 开 App → 逐房点缺勤 → 缺勤者默认 DS，可改 DB/XS/XB。
2. 若当天是周日返校，勾"生成周末返校统计"。
3. 点「上传标记件 →」。
4. 想立刻出表就点「立刻填表 ✓」；不点也会在 21:40 自动写。

### 管理者那一侧（控制台）

1. 打开 `https://ssdm.example.com/`（首次带 `?k=口令`，之后免）。
2. 看「今日一线」三格：
   - ① 点名件：到了没有、几人、是否含返校；
   - ② 待填计划：几份；
   - ③ 写入三表：今日是否已写、最近销账时间。
3. 有计划就点「试运行」看日志；无误再点「写入三表并销账」。
4. 想逐表核对：下方「待填计划」里有"将写主表第 N 行 · 体温 M 月 D 日 X 格"和可展开名单。

## 二、每周日：发布下周表

```
07:30  rc-publish 自动跑
- 取下一个周日的日期区间（周日~周四）
- 以标版生成两张 xlsx → 上传转在线表
- 命名 "%m.%d-%m.%d住宿生请假汇总表" / "周末未返校统计"
- 加群 EDITOR 权限、发链接给固定联系人
- 旧表撤权 + 改名 "已撤-"
- 回写 config：node / weekend_node / daterange
```

手动发布：控制台「发布周表」→ 选日期（或点本周/下周/上周）→ 看徽章与提示 →

- 提示"将撤下：11.01-11.05…" = 正常；
- 提示红字"⚠️ 该周已在役" = 重复发布，会撤掉自己正在用的表，除非确需重做。

## 三、每月 1 日：体温表

```
06:40  rc-tempmonth
- 发上个月的体温成品（分享链接给家长）
- 克隆上一月 sheet 为本月（重排日列：只留周日~周四）
- 学生行日列全部铺 RAND 公式（36.3~37.0）
- 发布共享表并撤旧
```

补漏：若某天发现当月 sheet 不存在，`fill` 会自愈（克隆最近月表、重排日列后再写），不会整晚停表。

## 四、每周五：备份

```
20:00  rc-backup
- 在线主表五块（C15:L15 … C111:L111）快照
- 周末表 B1 全片快照
- tar：data/ + app/data/宿舍点体温.xlsx + roster_b1f.json + ops/
→ /srv/dormroll/data/backup/  （周快照 json + ct102-data-YYYYMMDD.tgz）
```

## 五、异常处置

| 症状 | 判断 | 处理 |
| --- | --- | --- |
| 21:40 后表没更新 | 控制台「今日一线」②是否 0 份 | 让学生211重传；或看 `data/pending/` 有无计划 |
| 有计划但未写 | 看任务输出日志 | 点「试运行」定位；修好后「写入三表并销账」 |
| 体温表整列空 | 台账缺当月 sheet | 已自愈；仍空则看日志"缺 N 人（跳过）" |
| 某人没写进去 | 名字/房间与表不一致 | 加 `name_aliases` 别名，或在表上补行 |
| 表里出现 `#VALUE!` | 公式里加了文字占位 ` - ` | 用 SUM 形式（模板已统一） |
| 发布后家长打不开 | 权限没加或链接被撤 | 控制台「表指向」确认 node；重发权限 |
| 周日发布错周 | 日期选错 | 重选正确周再发；旧错表撤权改名 |

## 六、人工干预点（可以不动系统就改的）

1. **改目标表**：控制台「表指向」→ 选表 → 切换。用于临时把某类表指到别的文档。
2. **改请假口径**：iPad 上改四维重传；以最新一份为准。
3. **补某天**：把该天标记件重传 → 计划入信箱 → 控制台「写入三表并销账」。
4. **调休/补班**：`config.blockmap` 里给某日指定块号（0~4），覆盖"按星期推块"。
5. **撤某张表**：控制台「表格库」里"下载/预览"核对，或在钉钉侧撤权改名。

## 七、每天只需看三个地方

1. 「今日一线」三步是否绿；
2. 「最近记录」有没有"销账 当日"；
3. 「任务输出」有没有红字。
