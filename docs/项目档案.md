## 五、交接清单（新人接手照做）

1. 读 `README.md` → `00-项目说明.md`。
2. 读 `02-工作流程.md`，知道每天该看哪三处。
3. 读 `07-工作原理.md`，懂"件—计划—表"和"不销账等于没成"。
4. 拿控制台口令（`/srv/dormroll/ops/web_auth.txt`）登录一次，看「今日一线」。
5. `ssh langchao-wg` → `pct exec 102 -- bash`，确认两个服务在跑、五个 timer 在册。
6. 跑三条 dry：`fill --dry`、`publish <下周日> --dry`、`tempmonth <下月> --dry`。
7. 打开 `04-运维手册.md` 的故障表存到手机，出事照查。

## 八、变更规则

1. 改代码先备份同名 `.bak-日期`，本地 `py_compile` / `node --check` 过一遍。
2. 部署只推改动文件，只重启受影响服务。
3. 跑三条 dry + 控制台试运行，再点真填。
4. 在 `06-变更与踩坑.md` 记一笔：日期、改了什么、为什么、怎么验的。
5. 涉及表结构的改动，先在模板与在线表各留一份快照。

## 九、已知遗留

1. 日志无轮转，`fill.log` 与 `done/` 只增不减。
2. `/api/history`、`/api/students` 全目录扫描，件多会慢。
3. iPad 上传后缺一句"已上传 N 人，点此写入"的确认。
4. 控制台口令长期有效，未做短时效 token。
5. 预览有 2~5 分钟缓存滞后（下载是实时的）。
