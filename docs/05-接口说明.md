# 05 · 接口说明

## 一、一体机（应用容器:8100，对外 `https://example.com/dianming/api/`）

nginx 会把 `/dianming/api/` 前缀去掉，所以下表路径就是服务里的真实路径。

| 方法 | 路径 | 鉴权 | 作用 |
| --- | --- | --- | --- |
| POST | `/upload` | `token`（query 或 body） | 上传点名件（`.json.gz`），落 `data/marked`、算计划入信箱 |
| POST | `/write-now` | `admin` | 立刻填表：跑 `pipeline_ops fill --targets=main,weekend,temp` |
| POST | `/api/fill-now` | `admin` | 指定文件重算计划（旧入口） |
| POST | `/api/ack` | `admin` | 销账：`pending/<date>.json` 移到 `logs/done/` |
| POST | `/api/config` | `admin` | 读改配置（node / weekend_node / temp_node / blockmap / daterange …） |
| GET | `/api/pending` | `token` 或 `admin` | 待填计划（含 values/students/weekendN） |
| GET | `/api/history` | `admin` | 近 20 条记录摘要 |
| GET | `/api/students` | `token` 或 `admin` | 名册（按房/按班） |
| GET | `/list` `/index` `/latest` `/get` | `token` | 回执与点名件列表/下载 |
| GET | `/raw/<name>` | `token` | 原始件字节流（gzip） |
| DELETE | `/api/delete?name=` | `token` | 隐藏一份件（不物理删） |

示例（服务器上没有 curl，用 python 更稳）：

```python
import urllib.request, json
base = "http://127.0.0.1:8100"
req = urllib.request.Request(base + "/api/ack?admin=CHANGE_ME_ADMIN&date=2026-11-02",
                             data=b"{}", headers={"Content-Type": "application/json"})
print(urllib.request.urlopen(req, timeout=30).read().decode())
```

### 上传件格式（客户端 → 服务器）

```
POST /upload?token=<TOKEN>&name=20261102-153111.json.gz
Content-Type: application/gzip
<gzip 后的 JSON>
```

JSON：

```json
{"v":4,"type":"marked","d":"2026/11/2 15:31:01","weekend":true,
 "ref":"roll/20261102-153111.json.gz",
 "n":[["学生79 网络","103","XS"]]}
```

- `v=2,type=rollcall` 是旧版回执（只有数字行），`v=4,type=marked` 才有四维名单。
- `ref` 指回执名，便于回溯。

### 返回约定

成功 `{"ok":true,...}`；失败 `{"ok":false,"error":"..."}`。`/write-now` 额外返回 `log`（最后几行），`skipped:true` 表示已有进程在跑。

## 二、控制台（应用容器:8120，对外 `https://ssdm.example.com/`）

鉴权：Basic（脚本）或 `?k=<口令>` 一次性种 cookie（浏览器）。

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/` | 控制台页面 |
| GET | `/api/status` | 三表当前指向（名/建/改/链接）、原始件列表、任务日志 |
| GET | `/api/overview` | 今日一线：周区间、今日件、今日是否已填、最近销账、计划数 |
| GET | `/api/history` | `fill.log` 尾部 8 行 |
| GET | `/api/pending` | 待填计划（转发一体机） |
| GET | `/api/tables?kind=` | 某类可切换的在线表（main/weekend/temp） |
| GET | `/api/library?kind=` | 表格库：该类的历史表（按创建倒序） |
| GET | `/api/preview?node=&sid=` | 读在线表前 40 行 × 12 列（旧预览，保留） |
| GET | `/api/mark?f=` | 原始件解析（姓名/房号/四维/时间） |
| GET | `/api/raw?f=` | 原始件原文（解 gzip，pretty JSON） |
| GET | `/download/week?kind=` | 导出当前周表 xlsx（main/weekend） |
| GET | `/download/temp` | 导出当前体温表 xlsx |
| GET | `/download/table?kind=&node=` | 导出任意一张在线表为 xlsx（预览/下载用） |
| GET | `/download/mark?f=` | 下载原始件 |
| GET | `/static/<file>` | 预览组件（xspreadsheet / SheetJS） |
| POST | `/api/publish` | `{date}` 发布该周两表（后台任务） |
| POST | `/api/temp` | `{month}` 生成/发布该月体温表 |
| POST | `/api/setnode` | `{kind,node}` 切换表指向 |
| POST | `/api/fill` | `{targets:[...],dry}` 填表（dry=试运行） |
| POST | `/api/timer` | `{name,action}` action=on/off/run |

```python
import urllib.request, base64, json
auth = base64.b64encode(b"ssdm:ssdm2026!").decode()
req = urllib.request.Request("https://ssdm.example.com/api/overview",
                             headers={"Authorization": "Basic " + auth})
print(json.load(urllib.request.urlopen(req, timeout=60)))
```

## 三、iPad 客户端（DormRoll 1.1 / 20261102）

| 客户端动作 | 请求 |
| --- | --- |
| 上传标记件 | `POST https://example.com/dianming/api/upload?token=…&name=…`（gzip body） |
| 立刻填表 | `POST https://example.com/dianming/api/write-now?admin=…` |
| 删除服务器某件 | `DELETE …/delete?token=…&name=…` |

- 断网时全部落 `localStorage`，联网后按 `serverFileMap` 补传。
- 上传成功后显示「立刻填表 ✓」；点了即上表，不点等 21:40。

## 四、错误码与含义（一体机）

| 码 | 场景 |
| --- | --- |
| 400 | token 缺失/非法、请求体非法、日期名不合规 |
| 401 | admin 不对、token 不对 |
| 404 | 文件不存在 |
| 413 | 请求体超限（>500KB） |
| 500 | 内部异常（看 `journalctl -u rollcall`） |

## 2026-11-04 新增

### GET `/api/app/latest`（公开）
返回安卓最新包信息：`{ok, versionCode, versionName, file, url, sha256, size, notes}`。

### GET `/api/app/apk/<文件名>`（公开）
返回 APK 二进制（`application/vnd.android.package-archive`）；带 `?b64=1` 时返回 `{ok,file,size,sha256,b64}`，供客户端走文本通道下载。

### POST `/api/roster/import`（仅 admin）
自动更新住宿表：上传分布图 +（可选）个人信息表，服务端重建七层名册。

请求体（JSON，文件用 base64）：
```json
{"b": "<B座分布图 xlsx base64>", "a": "<A座分布图 xlsx base64>",
 "male": "<男生个人信息 xls base64>", "female": "<女生个人信息 xls base64>",
 "overrides": {"张三": "26商英2"},
 "confirm": false}
```
- `confirm` 缺省或 false → **只预演**，返回各层房数/人数与增减名单，不落盘；
- `confirm: true` → 真正写 `roster_*.json`（房号/床位取分布图，班级取个人信息表）；
- 鉴权：`Authorization: Bearer <RC_ADMIN>` 或 `?admin=<RC_ADMIN>`。

### GET/POST `/api/roster/sources`（仅 admin）
住宿表的“自动源”配置。GET 返回 `{cfg, state, log}`；POST 保存：
```json
{"sources":[{"key":"b","url":"https://…/B座.xlsx"},{"key":"a","url":"https://…/A座.xlsx"}],
 "apply": false, "overrides": {"张三":"26商英2"}}
```
`key` 取 `b / a / male / female`；`apply` 为 false 时抓到新文件只预演。

### POST `/api/roster/check`（仅 admin）
立刻跑一次看门脚本（`ops/roster_watch.py`），返回 `{code, out, log}`；code=0 无变化或已写入，code=2 有变化但只预演。

定时：`rc-rosterwatch.timer`，每天 06:30 与 18:30 各跑一次；日志 `data/logs/roster_watch.log`。

### GET `/api/app/latest-ios`（公开）
iOS 最新包信息：`{ok, version, build, notes, ipa_url, manifest_url}`；`manifest_url` 是 `itms-services://` 链接。

### GET `/api/app/ios/<文件名>`（公开）
静态分发 iOS 的 `.ipa` 与 `manifest.plist`（目录 `/srv/dormroll/app/ios/`）。

## 设备日志（2026-11-04 新增）

客户端把运行日志批量上报，管理端按设备/级别查询。

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/log` | 层令牌 | body：`{device, version, entries:[{t,level,tag,msg}]}`；单次 ≤200 条，单条 ≤1000 字，同设备每分钟 ≤30 次 |
| GET | `/api/logs` | 管理员 | `?limit=200&device=&level=`，返回最近日志（倒序） |

日志落 `device_logs` 表；控制台 `/logs` 页面可筛选查看（30 秒自动刷新）。
崩溃日志会在下次启动时补传（客户端持久化到 `logs_pending.json`）。
