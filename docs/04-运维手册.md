# 04 · 运维手册

## 一、在哪台机器

| 项 | 值 |
| --- | --- |
| LXC | 应用容器 `app-container`（内部服务器 虚拟化平台 9.2 上） |
| 内网 | `192.168.1.20`（LAN 192.168.1.10 同段） |
| 对外 | `example.com/dianming/api/` → 北京轻量 nginx → 宿主机 socat → `192.168.1.20:8100` |
| 控制台 | `https://ssdm.example.com/` → `:8120` |
| 代码 | `/srv/dormroll/` |
| 数据 | `/srv/dormroll/data/` |

进机器：

```bash
ssh langchao-wg                       # 到 虚拟化平台 宿主
pct exec 102 -- bash                  # 进 应用容器
```

## 二、服务与定时

| 单元 | 端口/时刻 | 说明 |
| --- | --- | --- |
| `rollcall.service` | 8100 | 一体机后端（上传/计划/销账） |
| `rc-web.service` | 8120 | 控制台（含 `/static` 预览组件） |
| `rc-publish.timer` | 周日 07:30 | 发布下周两表 |
| `rc-fill.timer` | 周日至周四 21:40 | 写三表 |
| `rc-sweep.timer` | 周日至周四 23:50 | 空箱补扫 |
| `rc-tempmonth.timer` | 每月 1 日 06:40 | 体温月表 |
| `rc-backup.timer` | 周五 20:00 | 备份 |

```bash
systemctl status rollcall rc-web
systemctl restart rollcall rc-web
systemctl list-timers 'rc-*'
journalctl -u rc-fill -n 50 --no-pager
tail -f /srv/dormroll/data/logs/fill.log
```

## 四、自测三条 dry

```bash
pct exec 102 -- bash -c 'cd /srv/dormroll && \
  python3 ops/pipeline_ops.py fill --dry && \
  python3 ops/pipeline_ops.py publish 2026-11-08 --dry && \
  python3 ops/pipeline_ops.py tempmonth 2026-12 --dry'
```

## 六、控制台口令

- 首次：`https://ssdm.example.com/?k=<口令>` → 种 cookie（HttpOnly）→ 302 到 `/`。
- 也支持 Basic 认证（脚本用）。
- 口令文件：`/srv/dormroll/data/state/creds`（丢失不要紧，但不要删库）。

## 七、常见故障速查

| 现象 | 先看 | 处置 |
| --- | --- | --- |
| 控制台打不开 | `systemctl status rc-web` | 重启；看 `journalctl -u rc-web -n 50` |
| 首页转圈/接口 500 | `journalctl -u rc-web` | 多为 dws 超时；稍后重试 |
| 上传 401 | iPad 的 token 是否与 `pipeline_ops.TOKEN` 一致 | 改客户端或改 token |
| 上传成功但无计划 | `data/pending/` | 看日志"标记件不在周日~周四"或 gzip 损坏 |
| 填表报"主表回读不符" | 日志里的行号与块 | 通常是 `blockmap` 或日期错；核对后重跑 |
| 体温整列没写 | `fill.log` 是否"缺 N 人（跳过）" | 补别名/补行；或看月 sheet 是否存在 |
| `#VALUE!` | 该格公式 | 改 `SUM(...)`；模板已统一 |
| 定时没跑 | `systemctl list-timers` | `systemctl start rc-fill` 手动触发看日志 |
| 磁盘涨 | `du -sh data/*` | 备份包与 marked 最占；保留最近 12 周 |

## 八、安全要点

1. 一体机只在内网，公网只经 nginx 的 `/dianming/api/`；`/raw/`、`/api/config` 需 token/admin。
2. 控制台所有写操作要求 `Content-Type: application/json`（防 CSRF），静态与下载路径做白名单与 `realpath` 校验。
3. 日志里不写 token；`?k=` 用完即 302 清地址栏。
4. 备份包含名册与体温表，注意存放位置权限（600）。

## 九、改代码的规矩

1. 先本地 `py_compile` + `node --check`（前端在 `PAGE` 里）。
2. 线上先备份同名 `.bak-日期`。
3. 只重启受影响服务；`rc-web` 重启不影响正在跑的一体机。
4. 改完跑三条 dry，再在控制台点一次「试运行」。
5. 记一笔到 `06-变更与踩坑.md`。
