## 三、铁律（写在这里，省得每次翻）

1. **内部服务器是生产机**。九只 LXC（应用容器–103、应用容器–110）＋ VM104 全挂在它身上。不得致死机／断网／CPU 满／内存耗尽／盘满／进程崩。严禁压测、洪水、DDoS、挖矿。它只做中枢。
2. **两屋共用 `/data`**，compose 文件名必须分开（`-jiqu.yml`／`-furina.yml`），否则互相覆盖。
3. **Mac 的 curl 测 example.com 一律 `HTTP 000`**（LibreSSL 无 TLS1.3）。验站用 python 或浏览器。
4. **动 wg0 peer 前先 `wg show wg0 peers`**。陌生的 key 就是新建 peer，会劫路由。
5. **停内网隧道前先 bootout 三个 LaunchDaemon**，别裸 `wg-quick down`。
6. **iSCSI 给 Mac 是死路**（macOS 27 砍了发起端）。走 SMB。
7. 敏感文件全在加密卷，**分享盘／归档包／仓库一律不进**。
