### 导航页口令门

- 口令 **`081126`**，只要口令、不要用户名、不记忆
- 凭据走请求头 **`X-NavKey`**，不写 cookie、不进 URL（`?k=` 与 `navok` cookie 已作废）
- 摘要 = PBKDF2-HMAC-SHA256(口令, salt=`example.com/nav-salt/2026`, 200000) = `949b95ef…f94c`（只存 nginx 里）
- 空 header → 302 `/gate.html`；错凭据 → **403（不是 302）**
- ⚠️ 摘要 64 字符超过 map 桶深 → `http{}` 里加 `map_hash_bucket_size 128;`
- ⚠️ **短板是口令本身**：六位数字裸 SHA-256 穷举 0.04 秒。别当它是真门
- 备退 `/etc/nginx/.htpasswd-nav` ＝ `Audrey` / `081126`（640 root:www-data）
- 回滚备份：`furina.conf.bak-hdr-*` / `.bak-nocookie-*` / `.bak-gate-*`

### 免口令路径的坑（2026-10-19 亲历）

`/xxjsx/` 无口令门，`location ^~ /xxjsx/` 独立于导航 gate。
但**不带尾斜杠的 `/xxjsx` 匹配不到 `^~ /xxjsx/`**，会掉进 `location /` 的口令判断被 302 到 `/gate.html` —— 看着像"要密码"，其实是路径没兜住。
已加 `location = /xxjsx { return 301 /xxjsx/; }`。

> **以后加任何免口令路径，都得同时给它补一条不带斜杠的精确跳转。**

### 验「大陆可达性」的可靠法子

Bash 沙箱出口走代理，`curl` 返 200 **不算数**。可靠两法：
1. 请姐姐实测
2. **`present_files` 打开 URL** —— 走 WorkBuddy 内置浏览器（＝姐姐本机真实网络），再查服务器 `access.log` 的来源 IP 交叉验证

⚠️ 电脑上挂着 VPN／代理会**接管外部浏览器**（内置 Electron 不受影响），极易误判成"网不通"。

## 四、云盾三道拦（记住这三条，省无数误判）

| 情形 | 表现 | 判定条件 |
| --- | --- | --- |
| 80 口 HTTP | 403 ＋ `Server: Beaver`，页标题 `Non-compliance ICP Filing` | **只认 Host 头域名 → 裸 IP 完全绕开** |
| 443 境外来源 | 直接 RST（curl 退出码 35，`Recv failure`） | **TLS 1.3 一样被 RST**，ICMP 却畅通 → **ping 通 ≠ HTTPS 通** |
| 443 国内来源 | 条件性 RST | **SNI 命中未备案域名 且 TLS ≤ 1.2**；TLS 1.3 正常（example.com 就这么跑） |

推论：**境外探针测自家未备案域名必全红**，探针必须放国内。Kuma 已从新加坡迁回内部服务器（10-14），现绑 `10.0.0.2:3100`，数据与账号 `AudreyLin` 一并迁了。

## 六、nginx 四坑

1. **密码文件权限**：`chmod 640` 必须配 `chown root:www-data`，否则 worker 读不到 → 认证失效，错密码还会返 500
2. **上传 413** = `client_max_body_size`（默认 1MB）。**每个 server 块须单写，不继承**
3. **改完必须 `nginx -s reload`**
4. **性能基线（勿回退）**：`furina.conf` 顶部 `map $http_upgrade $connection_upgrade` ＋ `upstream openlist_backend { keepalive 64; }`。原先把 `Connection "upgrade"` 写死 → 每个小请求都在 WG 上新开 TCP。OpenList 块要开 gzip
