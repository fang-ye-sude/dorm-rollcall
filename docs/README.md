# 宿舍点名 · 项目文档

> B 座住宿生「点名 → 填表 → 发布 → 备份」一体化系统。
> 本目录是**可独立交付**的项目册：需求、流程、实现、运维、接口、变更，一册齐全，不依赖本机记忆。

---

## 一句话说清

学生211在 iPad 上点完名 → 上传点名件 → 系统算计划 → 把「请假四维」写进三张共享表（请假汇总 / 周末返校 / 体温）→ 周日晚自动发下周新表 → 每周五自动备份。

## 谁在用

| 角色 | 做什么 | 用什么 |
| --- | --- | --- |
| 宿管老师（学生211） | 每晚点名、标记请假四维、上传 | iPad「B座点名」App |
| 家长（张昊天爸爸等） | 看请假汇总表 | 钉钉文档共享链接 |
| 学生296（管理者） | 发布周表、查看/修正、手动填表 | 网页控制台 |
| 系统 | 定时发布、定时填表、补扫、月表、备份 | 应用容器 上的 systemd 定时器 |

## 五个入口

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| 控制台 | `https://ssdm.example.com/` | 口令 `?k=` 或 Basic；管理一切 |
| 一体机 API | `https://example.com/dianming/api/` → `192.168.1.20:8100` | iPad 上传、计划、销账 |
| 请假汇总表 | 钉钉文档（每周新建） | 家长看 |
| 周末未返校统计 | 钉钉文档（每周新建） | 家长看 |
| 宿舍点体温 | 钉钉文档（每月新建） | 家长看 |

## 时间线（自动）

| 时间 | 任务 | 作用 |
| --- | --- | --- |
| 周日 07:30 | `rc-publish` | 发布下周两张表，撤旧表 |
| 周日至周四 21:40 | `rc-fill` | 取信箱计划，写三表并销账 |
| 周日至周四 23:50 | `rc-sweep` | 空箱补扫（漏传兜底） |
| 每月 1 日 06:40 | `rc-tempmonth` | 发上月体温表、生成本月空表 |
| 周五 20:00 | `rc-backup` | 在线表快照 + 全档打包 |
